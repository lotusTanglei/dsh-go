# 单一工作区 · 人工验收清单（未执行）

## 前提

**当前不能做生产验收。** L1/L2执行边界未通过，真实Worker已关闭；私有项目范围脱敏时计划不可批准。以下是未来经用户明确授权部署、解决安全与范围展示后，在实际连接GUI中的人工步骤，不是已做记录。

本轮没有浏览器控制、没有Desktop安装、没有凭据搜集、没有假DOM/截图。独立UI/UX代码审查和VM工厂注册均不证明页面实际可用。当前GUI是否加载新bundle须由受支持插件管理和真实资源检查确认；不能启动另一个Vite/HTTP服务器假装更新现有页面。

## 视觉、键盘与无障碍

- 明/暗主题分别检查标签、错误、disabled、焦点环、对比度；生产仅使用已核theme tokens不代表实际对比度已通过。
- 中文/英文无原始key、截断影响授权或关键按钮被挤走。
- 按容器宽度走查：>1050左任务/右304px沟通；≤1050完整任务/对话切换默认任务；≤720状态分组2×2；≤440单列。主区统一纵向滚动，不能横向裁掉末列。审计划/读回复临时扩大辅区，完整权限正文与确认可达。
- Tab/Shift+Tab到达搜索、chip、输入、卡片、更多、审批/停止；Enter/Space行为正确；状态不只用颜色。
- 详情/系统Escape关闭且焦点回原控件；二次确认真正modal、理由label可读，关闭后草稿/滚动保持；pending时关闭规则可理解。
- 读屏aria-live不过量重复轮询；标题/列语义明确；技术UUID默认折叠，仅需要时复制。
- console无slot/schema/closure错误、无卸载后setState噪音；Network无重叠轮询风暴、无错误0delay循环；关闭页面不调用后台cancel。

## 不能以人工点击补过的阻断

- 真实首工具前Ticket根隔离、shell/python/node/heredoc/后台逐路径授权必须有执行证据，不能靠看板显示或提示词承诺。
- 运行profile/依赖/核心/DDL/额外可写根等变化需单独授权；此清单不授予这些权限。
- 若功能仍不可用或精确范围不可审阅，必须保留失败/阻断，不用“视觉待人工”掩盖实现未闭合。
