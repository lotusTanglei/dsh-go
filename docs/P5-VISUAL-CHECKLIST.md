# P5 四页补齐：人工视觉验收清单

**当前结论：静态证据 ≠ 视觉通过；以下 8 项均未人工执行。**

客户端在当前连接的 Harness GUI 中未安装/挂载，不能把源码、构建产物或 Slot 声明检查写成运行页面验收。此清单不授权安装插件、修改 profile、启动替代服务器或发起真实业务动作。由有权限的验收人员在已部署的目标 GUI 执行；不要使用生产中的真实停止/批准操作作为试点。

自动证据边界：源码字段接线、本地化与保守未知值检查；**先由 lead 构建**，再检查 [客户端构建产物](<../lib/client.js>) 中 sidebar/main/superagent 标识、七页 i18n key、恰好三次 Slot 注册和主题 token。测试不模拟 DOM/React，不渲染截图，不证明实际布局、焦点、主题对比度、网络返回值或无控制台异常。

## 八条点击步骤（逐项记录主题、语言、结果与证据）

1. [ ] **发现入口、七页与主题。** 在已部署目标页打开侧栏「超管 / Superagent」，依次点击总览、任务、话题、来源、审批、健康、设置；切换浅/深主题，并在中/英语言各检查一次。期望：单个主面板有七个正确翻译的导航按钮；当前页可辨，无空白槽位、遮挡或 `slot entry crashed` 控制台错误；文字、边框、禁用态与宿主主题协调；窄窗口长 ID/JSON 换行，不横向挤出。
2. [ ] **保留总览和任务详情流程。** 点击「总览」后到「任务」，点一条安全 fixture 的「详情」，检查停止/恢复按钮，再打开确认框后取消。期望：总览真实计数/活动/健康状态与响应一致；缺失值显示未知/—，不伪造 0 或正常；任务详情/时间线正常；不可用动作 disabled；停止理由必填，取消不发送动作；Escape 可关闭，焦点回到原按钮。
3. [ ] **保留审批主流程。** 点击「审批」，展开 fixture 的详情，分别打开批准/拒绝确认框并取消；以 Tab 检查按钮和理由框。期望：摘要与影响范围可读；理由必填、空白时不能提交；取消/Escape 不改变审批，关闭后焦点返回触发按钮。真正批准/拒绝只在另行授权的可丢弃 fixture 上验收，不用生产记录。
4. [ ] **Threads 来源分组和分页。** 点击「话题」，对照 `/threads` 响应检查两个来源及一个无评估的 fixture；如有 `next`，点下一页/上一页。期望：按 source 分组，显示最后入站时间、创建时间、已持久 Trigger 消息数、订阅布尔/数量、真实 Eval state/ID、暂停与序号；无 Eval state 为未知，不拿 evaluating ID 冒充状态；页码动作只读取原路由，边界按钮禁用。此处消息数不是会话全文消息数。
5. [ ] **Sources 真只读暂停状态。** 点击「来源」，对照 `/health.sources` 的 id/kind/attended/ok/lastAt/paused；试点按暂停开关。期望：每项数据对应真实返回值，布尔暂停显示带 `role=switch` 的禁用开关，不能改变；缺失 paused 显示未知而非假关闭；没有新增 `/sources` 请求或暂停写操作。
6. [ ] **Settings 完整安全投影。** 点击「设置」，逐项对照 `/settings.effective`；检查布尔、0、数组/对象，以及 patch/environment/default/derived/unavailable 的 fixture。期望：全表不截断；值与来源分列、来源说明可读；stateDir/dbPath/lockPath/workRoot 或 redacted 字段的值仅为 `[REDACTED_PATH]`，没有绝对私有路径；无编辑/保存控件，不猜测缺失来源。
7. [ ] **Health 真实观测。** 点击「健康」，对照 `/health`。期望：展示真实 runtime、DB 迁移版本和字节数、Outbox pending/dropped、Watchdog 最后活动与最近最多 20 条判定、最近错误时间/动作/错误码。每条判定可见 at/action/rule/outcome/assignmentId 及 metrics 的 at/lastProgressAt/stallMs/durationMs/repeatedCalls/usage/steps/waitingMs；stallMs 是实测停滞时长不是阈值；缺项未知/—，不能伪造健康或全零。
8. [ ] **加载、未知与失败恢复。** 用授权 fixture 或 DevTools 受控响应分别验证明确空数组、缺字段、延迟、失败，再点击重试和切换页面。期望：空数组显示暂无记录，缺字段显示未知/—；错误有可见 alert 与重试，失败不伪造成功数据；恢复后读取真实新值，切页无旧页数据闪现；离开页面停止该页轮询，Sources 始终只读 health。不得为此改 profile 或启动替代服务。

记录模板：`序号 | GUI URL/部署版本 | 浅/深主题 | 中/英语言 | 通过/失败/未验 | 实际现象及控制台/网络证据`。仅在真实 GUI 完成对应项后方可标「通过」；静态测试通过只能记「自动静态通过」。
